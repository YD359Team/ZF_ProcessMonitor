# ZF_ProcessMonitor

## ENG

**ZF ProcessMonitor** is a simple application for monitoring processes, displaying programs in autorun, etc. \
It was created as an open source example for the [ZeppelinForms](https://github.com/YD359Team/ZeppelinForms-solution) UI framework,
in which the author could check the stability and convenience of the framework in "combat conditions".
